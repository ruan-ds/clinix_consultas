
# ADR 003 - Docker e o banco de dados

## Status
Definido

## Contexto
Precisávamos manter padronizado e sincronizado o banco de dados em todos os ambientes de desenvolvimento.

## Decisão
Alem do Alembic foi decidido o uso do banco de dados dockerizado.

## Consequências
- Padronização, sincronização e integridade em todos os ambientes de desenvolvimento
- Facilidade na identificação de erros
- Facilidade na manutenção do banco

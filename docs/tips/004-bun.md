# TIP 004 - Bun

## Fluxo básico Bun
- cd frontend
- bun install (instala todas as dependências listadas nos arquivos bun.lockb e package.json)

## Roda servidor frontend
- bun dev

## Funções extra
- bun add packageexemplo (adicionar dependencia)
- bun remove packageexemplo (remover dependencia)
- bun run script (roda um script definido no package.json)
- bun build (compila o projeto se estiver usando Bun para bundling ou TS)

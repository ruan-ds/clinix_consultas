# Alterar commit local
- git log --oneline -n 5
(-n 5 limita a exibição aos últimos 5 commits. Remova -n 5 para ver todos os commits da branch)

- git rebase -i HEAD~3
(-i = interativo, HEAD~3 = os ultimos 3 commits (de cima para baixo no log), esse comando abrirá o editor configurado)

No editor (ex: VS Code), você verá algo assim:
pick abc123 Commit 1
pick def456 Commit 2
pick ghi789 Commit 3

Comandos dentro do editor:
- pick - mantém como está
- edit - altera o conteúdo do commit
- reword - altera a mensagem do commit
- squash - junta o commit com o anterior

Exemplo para editar o commit 2:
pick abc123 Commit 1
edit def456 Commit 2
pick ghi789 Commit 3

Salve e feche o editor.

O editor abrirá novamente para você alterar o conteúdo ou a mensagem do commit.
Exemplo:
~~Commit 2~~
Commit 2 corrigido

- git rebase --abort 
(para cancelar o rebase a qualquer momento)

- git add .
  git rebase --continue
  (para continuar depois de editar (edit) o conteúdo de um commit)

# Remover arquivos da stagging area ("pós git add")
- git restore --staged .

# Visualizar o conteúdo de um commit específico
- git show 8d1bb16

# Ver somente os nomes dos arquivos alterados nesse commit
- git show --name-only 8d1bb16
